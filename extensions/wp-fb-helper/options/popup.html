WP FB Helper

Toolbar = settings. Facebook = panel like Flow Hub.

Login + Application Password together. Plugin: Easy MCP Post Extra Fields 1.3.6+ (folder easy-mcp-post-meta).

0 = off. Minimum 1 second. Quiet refresh: open panel, filters, Extra text, scroll and selection stay put.

Dock icon mode

Fixed = icon always visible. Edge = near screen edge. Hidden = no icon. About the icon, not the modal.

When on: only vertical move + arrows on the dock; clicks/hover do not open the modal.

At edge: after the cursor leaves the 18px screen edge (and the tab), wait this many ms then hide the tab. Move the mouse to the edge to show it again. Turn off Configure position or the tab stays visible.

After leaving the open modal, wait ms before closing (0 = never).

Hover the dock icon to open the modal (disabled while position setup is on).
